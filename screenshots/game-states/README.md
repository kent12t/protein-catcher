`before-` files show the stacking regression; `after-` files show the correction.

- `01-title`: title screen
- `02-calculator-empty`: calculator before weight entry
- `03-calculator-filled`: calculator with a calculated goal
- `04-ready`: instructions and countdown
- `05-playing`: active game with falling food
- `06-ending`: final seconds of the game
- `07-summary-lose`: unsuccessful result and mix-and-match guide
- `08-summary-win`: successful result and mix-and-match guide
